# Issue tracker configuration

**Tracker:** GitHub (`Divkix/Logwell`)

This repo uses GitHub Issues for feature requests, bug reports, and task tracking.

## How to use it

- Use `gh issue create` to file new issues.
- Use `gh issue list` and `gh issue view` to read existing issues.
- Update labels and status with `gh issue edit`.

## PRs as a request surface

No. External pull requests are not pulled into the triage queue.
