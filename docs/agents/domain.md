# Domain docs

## Layout

Single-context. The project has one global context file at the repo root.

## Files

- `CONTEXT.md` — domain language, product concepts, and consumer rules
- `docs/adr/` — architectural decision records

## How to read them

- Read `CONTEXT.md` before working on a feature to learn the project's domain vocabulary.
- Read `docs/adr/` before proposing changes that affect architecture, data flow, or deployment.
